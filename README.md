# 8086 and Assembly Visualizer

Animated, chapter-by-chapter lessons for the course **Microprocessor and Assembly Language**, prepared by Abduz Zami, Lecturer in CSE at BUFT.

- 11 chapters and 101 topics, each with step-by-step animations
- Voice-over in English and Bangla, with a choice of voice, tone and speed, and a voice on/off switch
- Captions and transcripts for every step
- An interactive quiz after every topic
- Interactive tools: number converter, segment:offset calculator, ALU/flags, shift/rotate, jumps, MUL/DIV
- Works on phones and desktops, in light and dark mode

## Open it
The whole site is the single file `index.html`. Open it in any modern browser, or publish it with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Voices
The voice-over uses the voices installed on the student's device. For the best Bangla voices (Nabanita, Pradeep, Tanishaa, Bashkar), open the site in Microsoft Edge. On Android, go to Settings → Text-to-speech → Google → Install voice data and add Bengali.
